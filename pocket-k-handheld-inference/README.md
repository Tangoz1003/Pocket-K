## De-Identification Note

The bundled demo ECG arrays are deterministic synthetic waveforms generated by `code/make_demo_data.py`. They are included only to demonstrate file format, inference calls, and output schema. The demo metadata does not contain patient IDs, encounter IDs, exact acquisition times, lab collection times, or other direct identifiers.

## Model

Checkpoint:

`model/pocket_k_model.pth`

Architecture:

`code/net1d.py`

The model is a 1-lead ECGFounder/Net1D binary classifier. It outputs one logit, converted to `pred_prob` with sigmoid.

The checkpoint is tracked with Git LFS in this repository template because it is larger than GitHub's regular Git file-size limit.

## Standard 10-Second Backend Inference

Expected ECG input:

- `.npy`
- accepted shapes: `(time, 12)`, `(12, time)`, `(1, time)`, or `(time, 1)`
- sample rate: 500 Hz
- lead used: I

Preprocessing:

1. Replace NaN/Inf with `0`
2. Convert to lead-first format
3. Select lead I
4. 50 Hz notch filter
5. 0.5-40 Hz band-pass filter
6. Median-filter baseline removal
7. Center crop or zero-pad to `5000` samples
8. z-score normalize the 10-second ECG

## Handheld 30-Second Reference Pipeline

`code/handheld_pipeline.py` implements the backend side of the handheld proof-of-concept inference flow. It starts from an anonymized ECG array supplied by a paired app, file upload, or another acquisition layer. Bluetooth acquisition and mobile UI code are intentionally outside this backend package.

The handheld pipeline is model- and platform-agnostic at the scoring boundary:

1. Accept one anonymized 30-second Lead I or 12-lead ECG array
2. Convert to Lead I
3. Resample to 500 Hz if needed
4. Apply the same deployment filtering
5. Crop or pad to 30 seconds
6. Split into three consecutive 10-second clips
7. z-score normalize each clip
8. Score each clip through an inference function
9. Average the three clip scores into one measurement-level `pred_prob`

This aggregation is used only for the handheld proof-of-concept path. The standard retrospective/deployment script uses one 10-second ECG per prediction.

## Output

The public reference implementation reports continuous model scores:

```text
pred_prob
```

Operating thresholds are deployment- and site-specific and are intentionally omitted from this public demo package. For a private deployment, add a private `thresholds` object to `config/deployment_config.json` with `low_risk_threshold` and `high_risk_threshold`; the code can then add a categorical `risk_group` without exposing the cutoff values in the API response or demo CSV.

Important:

`pred_prob` is a model risk score, not a calibrated absolute probability. Do not display `pred_prob` as the literal probability of hyperkalemia unless local calibration has been performed.

## Smoke Tests

Regenerate synthetic demo data:

```bash
python code/make_demo_data.py
```

Run standard 10-second inference:

```bash
python code/deploy_test_inference.py --device cpu
```

```bash
python code/handheld_pipeline.py --device cpu
```

Expected standard-output file:

`test_outputs/sample_predictions.csv`

## FastAPI Service

Install dependencies on the deployment server if needed:

```bash
pip install -r requirements.txt
```

Start the API service from the package root:

```bash
uvicorn code.api_server:app --host 0.0.0.0 --port 8000
```

Health check:

```bash
curl http://127.0.0.1:8000/api/health
```

Predict from a 10-second ECG `.npy` path:

```bash
curl -X POST http://127.0.0.1:8000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"ecg_path": "test_data/ecg_npy/demo_ecg_000.npy", "sample_id": "demo_001"}'
```

Predict from a 30-second handheld measurement `.npy` path:

```bash
curl -X POST http://127.0.0.1:8000/api/predict_handheld \
  -H "Content-Type: application/json" \
  -d '{"ecg_path": "test_data/ecg_npy/demo_handheld_30s.npy", "sample_id": "demo_handheld_001", "source_sample_rate": 500}'
```

Upload endpoints are also available:

```text
POST /api/predict_upload
POST /api/predict_handheld_upload
```
